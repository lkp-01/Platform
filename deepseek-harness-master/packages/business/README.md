# business/ — Business demonstrations

English | [中文](README.zh.md)

## Summary

Use local business tools to demonstrate distinct Agents over one Harness core. Customer, data and operations tools live in one package with separate entry points. The optional business bundle composes them into named presets. External systems are outside this group.
